# Inventory Management App

CSVマスタを読み込んで在庫状況を可視化する React + TypeScript アプリです。

## セットアップ

```bash
npm install
npm run dev
```

## 主な機能

- CSVアップロード、前回アップロードとの差分表示
- 商品名、カテゴリ、商品コード検索
- カテゴリ絞り込み、在庫数・販売価格ソート、20件ページネーション
- 在庫切れ・残りわずか・在庫ありのステータスバッジ
- アラート商品のみ表示、アラートライン変更
- サマリーダッシュボード
- 表示中リストとアラート商品のCSVエクスポート
- localStorage によるアップロードデータ保持
