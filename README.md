# Inventory Management App

在庫リスト（Excel・CSV）を読み込んで在庫状況を可視化する React + TypeScript アプリです。

## セットアップ

```bash
npm install
npm run dev
```

## 主な機能

- Excel（.xlsx / .xls）・CSVアップロード、前回アップロードとの差分表示
  - 在庫数は「販売可能数」列を優先して取り込みます（ECサイトの在庫数）
  - 「バリエーション」列がある場合は商品名に付けて表示します（`Default Title` は除く）
- 商品名、カテゴリ、商品コード検索
- カテゴリ絞り込み、在庫数・販売価格ソート、20件ページネーション
- 在庫切れ・残りわずか・在庫ありのステータスバッジ
- アラート商品のみ表示、アラートライン変更
- サマリーダッシュボード
- 表示中リストとアラート商品のCSVエクスポート
- localStorage によるアップロードデータ保持
